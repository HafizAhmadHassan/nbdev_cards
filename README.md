# Deck of Cards (nbdev)

A minimal **nbdev** tutorial project demonstrating how to create a **deck of cards** Python library.

## Overview

A small tutorial that follows the standard nbdev / fastai workflow: write notebooks, generate a Python package, and publish documentation with Quarto.

## Repository Structure

```
├── nbs/           # Development notebooks
├── nbdev_cards/   # Generated Python package
└── site/          # Rendered Quarto documentation
```

## Tech Stack

Python, nbdev, Quarto, Jupyter.

Completed tutorial project.
